# Exam Seating Planner

A single-page tool for making black-and-white exam hall seating charts.

- One student per desk; rooms set by capacity and desks per row
- Classes entered by first roll number and student count
- **Alternate grades in each row**: one class per column, no two students of the same grade side by side or diagonal
- **Roll number order**: seat everyone straight through, column by column, room by room
- Prints one A4 page per room (portrait or landscape to suit the room), plus a notice-board page

Live: https://v1kasjain.github.io/exam-seating/

Everything runs in the browser. Data you type is saved only in your own browser (localStorage); nothing is sent anywhere.
